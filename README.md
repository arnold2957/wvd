## 项目简介

wvdas 是一款面向手游《Wizardry Variants Daphne》（巫术 Variants Daphne）的自动挂机脚本，内置图形界面，覆盖日常刷图、任务洞窟、悬赏、矿石采集、钓鱼、战斗策略与异常恢复等流程。

与通用型自动化脚本相比，wvdas 针对本作中常见的 **网络波动、模拟器卡顿、游戏闪退、画面卡死、ADB 连接异常** 等情况做了专门处理，并提供任务级与任务点级的独立配置能力。

脚本支持简体中文与英文两种游戏界面。

## 功能特性

### 1. 运行稳定性与自动恢复

- **游戏自动重启**：检测到画面长时间静止、定位失败次数超限、宝箱或战斗耗时异常、连续点击 Resume 无响应等情况时，自动重启游戏。
- **网络异常处理**：自动识别并点击 Retry；遇到返回标题、重新下载等界面时按预设流程恢复。
- **ADB 自动恢复**：ADB 离线、连接超时或设备丢失时，自动结束并重启 ADB 服务。
- **模拟器自动恢复**：连续重启游戏超过设定次数后，自动重启模拟器；支持读取并结束已存在的模拟器进程。
- **启动前自检**：启动时检查模拟器与 ADB 状态，必要时自动启动模拟器并建立连接。
- **卡死检测**：基于连续截图差异判断画面是否静止；全黑截图会被跳过，以降低误判。
- **异常画面兜底**：无法识别的界面会尝试返回、点击安全位置，并在达到最大尝试次数后重启游戏。
- **模拟器路径校验**：检测到疑似错误的模拟器路径时弹窗提示。
- **空气墙处理**：可选的“重启后尝试绕过空气墙”功能；Resume 连续点击超过 20 次会判定为卡住并重启。
- **多显示器兼容**：模拟器存在多个显示端口时，优先使用默认显示器。

### 2. 任务与地图系统

- **任务分类浏览**：按“最新任务、主线前三章、主线第四章、任务洞窟、FFXI 联动、矿石、月常、其他、自定义”分类。
- **任务提示**：任务带有 `_TIPS` 时，选择任务后强制弹出说明窗口，并在日志中输出。
- **任务点系统**：地下城任务可拆分为多个任务点，逐点寻路、逐点执行。
- **楼层检测**：打开地图时校验当前楼层标题，支持同一楼层的多种标题尺寸；检测失败会保存截图并自动退出错误楼层。
- **地图寻路**：支持按方向拖动地图、区域裁剪、目标点二次确认、哈肯/大哈肯搜索、楼梯与跨楼层移动。
- **自动搜索**：支持面板上的“自动宝箱”（`chest_auto`）与“自动标记寻路”（`mark_auto`），并在按钮不可用或路径不存在时自动退出搜索。
- **直接退出地下城**：任务可使用 `leaveDung` 直接退出副本；该指令适用性有限，需谨慎配置。
- **时空跳跃**：自动完成诅咒之轮的时间跳跃，并可选择跳跃目标节点。
- **因果调整**：跳跃前可自动关闭未指定的因果，并按任务配置开启目标因果。
- **善恶调整**：遇到伏击/无视事件时，按面板设定的方向自动调整善恶值。
- **自动快进**：识别到对话快进关闭时自动开启。
- **特殊对话处理**：可识别并处理常见对话选项，包括购买骨头、尸油等；任务也可配置专属对话选项与回调。
- **特殊杂物切换**：开箱时检测指定杂物，命中后自动切换到另一任务（例如水路船一妖精、要塞八层妖精）。
- **关键事件停止**：任务可配置特定图片作为强制停止条件。

### 3. 战斗系统

- **战斗策略组**：为每个角色配置技能槽位（左上/右上/左下/右下/防御）、技能等级（1–7）与执行顺序。
- **策略重置**：
  - 每次启动脚本、重启游戏、角色死亡或再起后自动重置；
  - 可按策略组设置“进入地下城时重置”；
  - 高级选项支持“每场战斗开始前重置”；
  - 支持“释放任一技能即视为本组完成”。
- **全自动战斗**：策略为空、角色未匹配或策略名为“全自动战斗”时，自动双击开启游戏内自动战斗。
- **自动战斗状态检测**：识别自动战斗按钮的启用/禁用状态，必要时自动开启。
- **二倍速**：进入战斗后自动尝试开启二倍速。
- **技能等级降级**：SP/MP 不足导致目标等级技能无法释放时，自动改用 1 级技能重试。
- **单体目标选择**：通过方向场卷积识别敌方指示箭头（灰度与 R 通道分别检测），优先点击箭头附近目标；未识别到箭头时在敌方区域随机点击。
- **辅助技能**：支持辅助技能释放；目标可由策略配置指定。
- **复活与再起**：自动处理队友阵亡、多人阵亡与再起界面；再起后自动执行恢复。
- **任务点级策略**：可为同一任务的每个任务点指定不同的战斗策略，任务点完成后自动切换。

### 4. 探索、开箱与恢复

- **快速开箱**：跳过额外检测，指定开箱角色后快速连续点击开锁。
- **开箱人选**：支持随机或固定位置角色；指定角色恐惧/石化时自动改用其他角色。
- **自动恢复**：可分别配置战斗后、开箱后、进入地下城时与住宿后首次进本的恢复；角色复活后会强制执行一次恢复。
- **旅店休息**：支持按“完成 N 次地下城后休息”的间隔设置；未发生战斗或宝箱、关闭休息、或未达到间隔时自动跳过。
- **豪华房**：可选住宿时优先选择豪华房。
- **定时重置队伍**：可设置每 1–12 小时重新召集酒馆队伍，用于清理背包与调整站位。
- **地下城完成统计**：记录完成次数、总用时、上次用时、开箱次数与平均耗时、战斗次数与平均耗时。

### 5. “0 火”后的资源循环

当检测到“再起之火”耗尽时，脚本可按面板设置自动切换任务，优先级如下：

1. **挖矿**：切换到 FFXI 挖矿任务；
2. **刷钱**：切换到“7000G”任务；
3. **钓鱼**：切换到钓鱼任务。

若三项均未启用，脚本会等待约 2 小时后重启游戏，以重新点火。

- **钓鱼**：
  - 通过方向场卷积与模板匹配检测鱼漂，检测不到鱼漂时拉杆；
  - 自动检查鱼饵余量，耗尽时回城从仓库补充并返回钓点；
  - **不会购买鱼饵**，仅使用仓库中已有的鱼饵；
  - 统计鱼的大小（小/普通/大）与种类（鲈鱼、雅罗、鲶鱼、鳟鱼、鳗鱼、三文鱼、杂鱼等），未收录鱼类会保存截图；
  - 每次成功钓鱼保存截图；
  - 当前提供“近端钓鱼”任务，可从主城或钓鱼界面启动。
- **FFXI 挖矿**：
  - 自动前往标记矿点、连续挖掘、识别产出；
  - 统计全改、下改、衔尾蛇、精炼石、改造石、银矿石、特级/上级/中级/下级矿石等数量；
  - 挖到“全改”时自动截图；
  - 鹤嘴锄耗尽时退出副本、回城并重新召集 `FFXIStone` 队伍补充。
- **刷钱**：自动完成“7000G”时间跳跃、返回要塞、前往王城、领取与提交任务。

### 6. 日常 / 周常辅助

- **官网领取 50 钻**：提供新旧官网入口，按周判断并在需要时高亮提醒。
- **灵庙刷新提醒**：按双周周期判断，提供“灵庙已刷新”一键切换到灵庙任务。
- **月常任务分类**：炉壶灵庙、战士灵庙、钢试炼、蝎女悬赏等。

### 7. 数据统计与日志

- 界面摘要区实时显示：
  - 已完成地下城次数、总用时、上次用时；
  - 箱子效率（秒/箱）、累计开箱次数、平均开箱耗时；
  - 累计战斗次数、平均战斗用时；
  - 钓鱼与挖矿的专项统计；
  - 重要事件（角色死亡、再起、善恶变化、购买骨头/尸油、任务切换等）。
- 日志按天轮转，默认保留 3 天；截图与日志会定期清理。
- 重启前截图、楼层检测失败截图、钓鱼成功截图、挖矿特殊产出截图等均保存在 `logs` 目录。

### 8. 自定义与本地化

- **自定义任务**：通过 `mod/quest.json` 添加任务，支持自定义任务点、进入路线、回城路线、楼层检测、提示、特殊对话与特殊杂物回调；与内置任务代号冲突时会自动改名。
- **自定义图片**：可放置于 `mod/images/` 或 `mod/` 下，作为内置图片缺失时的补充。
- **界面语言与游戏语言分离**：脚本界面语言与游戏内语言可分别设置为 `zh_CN` 或 `en_US`。
- **自动更新**：定期检查 GitHub Releases；发现新版本后可自动下载（带进度条）或手动下载，更新完成后自动重启。版本变更时会弹出更新日志。

## 安装与启动

### 1. 安装模拟器与游戏

1. 下载并安装 MuMu 模拟器。
2. 安装游戏 APK。
3. 首次启动如遇黑屏，请安装 Google 三件套；MuMu 桌面通常提供一键安装入口。
4. 如遇 Google 登录弹窗，连续按返回键即可。
5. 如遇“违反安全策略”，请关闭 Root。
6. 如遇 `unable to initialize the unity engine graphics API`，先切换 DirectX 启动，再切回 Vulkan 启动。
7. 在模拟器设置中开启 **ADB 调试**。
8. 将分辨率设置为 **1600 × 900，240 DPI**。
9. 关闭模拟器的 **网络桥接模式**。

### 2. 模拟器路径与 ADB 地址

在脚本“模拟器”分组中设置：

| 模拟器 | 可执行文件路径 |
| --- | --- |
| MuMu 15 | `Netease\MuMu\nx_device\15.0\shell\MuMuNxDevice.exe` |
| MuMuX | `Netease\MuMu\nx_device\12.0\shell\MuMuNxDevice.exe` |
| MuMu 12 | `Netease\MuMu Player 12\shell\MuMuPlayer.exe` |

- **ADB 地址**默认为 `127.0.0.1:16384`。少数情况下端口可能为 `5555`，也可从多开管理器中查询。
- 输入纯端口号（如 `16384`）或 `5555,16384` 时，脚本会自动补全为 `127.0.0.1:16384`；也支持直接填写完整地址。
- **模拟器编号**用于多开场景，指定需要连接的第几个模拟器实例。
- 多开时建议关闭目标模拟器，让脚本自行启动，以免重启模拟器时影响全部实例。

### 3. 游戏内设置

为保证图像识别稳定性，建议按以下方式设置游戏：

- 画面质量：**中（速度优先）**。
- 帧率：**30 FPS**。
- 地下城亮度：**最暗至 25% 亮度**之间。
- 自动恢复：勾选“使用技能驱散异常状态”。
- 背包补充：
  - 勾选“将非补充对象的道具存入仓库”；
  - 勾选“与旅店住宿时自动补充”；
  - 如补充按钮不可用，可勾选“持有 1 个哈肯的钩爪”。
- 自动移动：一般关闭“优先不推进任务的路线”；刷矿石 plus 等特殊地图时按要求开启。
- 地图缩放：**保持未缩放**。未缩放的地图约为 17 个格子；如已缩放，建议重装游戏。
- 计划使用的技能必须放入**快捷栏**。
- **关闭对话自动选择分支**。部分任务（如 7000G 与特殊对话任务）依赖脚本自行选择对话。
- 地下城中展开地图下方的**快捷按钮栏**。
- 有时间跳跃内容的任务，建议先手动完成一次或全程观察首次运行，避免特殊剧情导致流程中断。
- 游戏地图必须**探明所有区域**；使用目标点判定的地图，至少需要探明目标区域。
- 建议提前解锁目标地图对应的大哈肯。
- 若角色进入副本后无法移动，通常是网络问题，请更换加速器。

### 4. 启动脚本

**图形界面模式：**

1. 双击 `wvd.exe`，或运行 `python src/main.py`。
2. 在“模拟器”分组设置路径与 ADB 地址。
3. 在“目标”分组选择任务类别与任务。
4. 根据任务需要调整“探索”“战斗”“高级”等设置。
5. 点击“脚本，启动！”。

**无头模式：**

创建 `wvd.exe` 的快捷方式，在“目标”一栏末尾添加：

```text
-headless
```

命令行同时接受 `-config <路径>` 参数。当前版本的无头模式从工作目录读取 `config.json`；如需使用其他配置，请先将其设为工作目录下的 `config.json`。

无头模式会直接读取配置并启动任务，日志输出到控制台与 `logs` 目录。

### 5. 配置文件

- 配置文件为工作目录下的 `config.json`，由图形界面自动保存。
- 每个任务可启用“用任务定制的配置文件覆盖默认配置”，独立保存探索、战斗与高级设置。
- 如配置异常导致无法启动，可备份后删除 `config.json`，让脚本重新生成默认配置。

## 脚本配置说明

### 模拟器

| 设置项 | 说明 |
| --- | --- |
| 模拟器路径 | 指向 MuMu 模拟器可执行文件；路径异常时会弹窗提示 |
| ADB 地址 | 默认 `127.0.0.1:16384`，支持完整地址与自动补全 |
| 模拟器编号 | 多开时指定模拟器实例序号 |
| 本脚本的语言 | 界面语言：`zh_CN` / `en_US`，修改后需重启脚本 |
| 游戏内的语言 | 游戏界面语言：`zh_CN` / `en_US`，必须与模拟器内游戏一致 |

### 目标

| 设置项 | 说明 |
| --- | --- |
| 任务类别 | 按分类筛选任务 |
| 任务目标 | 选择具体任务 |
| 任务定制配置 | 为当前任务单独保存一套配置；“清除”可删除该任务的定制配置 |

选择任务后，若任务带有提示，会弹出任务说明窗口。

### 探索

| 设置项 | 说明 |
| --- | --- |
| 开箱人选 | 随机，或固定为左上/中上/右上/左下/中下/右下 |
| 快速开箱 | 不进行额外检测，快速连续开锁；需要足够开锁能力 |
| 在战斗结束后进行恢复 | 战斗结束后执行自动恢复 |
| 在开箱后进行恢复 | 开箱结束后执行自动恢复 |
| 在进入地下城时进行恢复 | 每次进入地下城时恢复一次 |
| 在住宿后首次进入地下城时进行恢复 | 住宿后的首次进本恢复 |
| 启用旅店休息 | 关闭后跳过旅店休息 |
| 完成 N 次后休息 | 每完成 N 次地下城休息一次 |
| 善恶 | 设置善恶调整方向，并显示剩余调整点数 |
| 启用定时重置队伍 | 每 1–12 小时重新召集酒馆队伍 |

**回城与休息判定：**

- 未发生战斗或宝箱时跳过住宿；
- 关闭“启用旅店休息”时跳过住宿；
- 未达到休息间隔时跳过住宿；
- 启用定时重置队伍时，达到时间间隔后会回城重置队伍。

### 战斗

| 设置项 | 说明 |
| --- | --- |
| 全程策略 | 整个任务使用同一套战斗策略 |
| 自定义任务点策略 | 为每个任务点分别指定策略；需要启用任务定制配置 |
| 战斗方案 | 管理角色技能组、重置规则与完成规则 |

### 战斗方案

战斗方案由若干“策略组”组成，每组包含：

- **策略组名称**；
- **角色**；
- **技能槽位**：左上技能、右上技能、左下技能、右下技能、防御；
- **技能等级**：1–7；
- **进入地下城时重置**；
- **[高级] 战斗开始前重置**；
- **[高级] 释放任一即视为完成**。

执行规则：

1. 脚本按策略组中的顺序匹配当前行动角色。
2. 命中后释放对应技能，并将该条目从当前策略队列中移除。
3. 若开启了“释放任一即视为完成”，释放任一技能后清空当前策略。
4. 角色不在策略中、策略为空或策略名为“全自动战斗”时，执行游戏内自动战斗（双击自动）。

> 游戏会在角色死亡或游戏重启后丢失“重复上一次”状态，因此脚本会在这些时点自动重置策略。  
> 开启“每场战斗开始前重置”前，请确认你理解游戏内“重复上一次”的行为。

示例：
- 我想让柚子复读千紫万红 3： 
  战斗方案写一条“柚子，千紫万红，3”；游戏内设置柚子的自动方案为“重复上一次”。 
- 我想让叶卡每场战斗仅释放一次 AOE，并在之后进行自动攻击： 
  战斗方案写一条“叶卡，AOE，1”；脚本设置开启“每场战斗重置”；游戏内设置叶卡的自动方案为“攻击”。 
  脚本释放一次叶卡 AOE 后，策略为空，此时执行游戏内的自动方案；游戏内的自动方案为攻击，那么叶卡会持续攻击。 
- 我想让面具人进行动静裂地循环： 
  战斗方案写 2*n 条：第一条“面具，动静，1”；第二条“面具，裂地，1”；然后按照你的喜好重复若干次。

## 重点任务配置指南

### 水路船一妖精

- **前导任务**：请在船一 `x=4, y=25` 处打上标记，并确保这是船一唯一标记。
- 前导任务会反复进入船一并开箱，检测到妖精杂物后自动切换到后续任务，之后不再回到前导任务。
- 启动前请先按后续任务的需求配置好面板，包括是否禁止回城、战斗策略、任务定制配置等。
- **后续任务**：循环刷取，也可直接启动。

### 要塞八层妖精

- 前导任务反复刷要塞八层门口的两只怪并开箱，检测到妖精杂物后自动切换到“陷阱”后续任务。
- 后续任务循环刷取门口与陷阱房怪物。
- 该队伍通常**不回城**，推荐使用忍者、盗贼、面具人，搭配物理长矛/弓箭与王女或夏莉莉作为治疗。
- 在“设置 → 自动移动”中关闭所有选项。
- 前导任务与后续任务的队伍、自动移动与标记准备需保持一致。

### 沙人缘

- 脚本会自动完成三次沙人缘交互，完成后进行时间跳跃并结算。
- 任务运行中可通过停止按钮中止。
- 该任务会强制关闭“定时重置队伍”和“绕过空气墙”。

### 钢试炼

- 任务分类为“月常”，用于完成每周/活动任务的委托部分。
- 请打上两个标记：一个标记最终 Boss，一个标记左路物理路线。
- 使用 `mark_auto` 加速流程。

### FFXI 挖矿

请按以下步骤准备：

1. 购买 9999 个鹤嘴锄并保存在仓库。
2. 六人队伍脱掉所有装备，尽可能多地携带鹤嘴锄。
3. 在王城工会新建队伍并命名为 `FFXIStone`。
4. 前往活动地图 2F，在哈肯正对的矿点前打上标记。
5. 确保这是该层唯一的标记。
6. 在副本内或主城启动脚本。

补充说明：

- 鹤嘴锄耗尽后，脚本会退出副本、回城并重新召集 `FFXIStone` 队伍。
- 若在楼层选择处卡住，请尝试开启所有哈肯。
- 挖到“全改”时会自动截图。

### 钓鱼

- 当前提供近端钓鱼任务，可从主城或钓鱼界面启动。
- 支持回城补充鱼饵，但**只会使用仓库中已有的鱼饵，不会购买**。
- 鱼饵耗尽时自动回城补充并返回钓点。
- 自动统计鱼类大小与种类；未收录鱼类与每次成功钓鱼都会保存截图。
- 0 火耗尽时可自动从第四章“美丽矿石的真相”节点继续。

### 悬赏：蝎女

- 推荐刷 7 级悬赏蝎女。
- 前排约 180 闪避即可基本避免被命中；后排不会被连续针对。
- 参考阵容（不释放攻击技能）：
  - 前排：堆叠 180 闪避的牧师，以及任意角色（推荐忍者）；
  - 后排：正常堆攻击的长枪/弓箭战士，或堆攻击的苦无忍者。
- 装备足够时可使用“蝎女 + 风暴六手”连刷任务。

### 死神暗灯

- 用于刷取暗抗装备与小号经验。
- 怪物攻击较高，建议每人都持有光属性武器（或若干先驱斩）后再尝试。
- 在死神地图左上角与门交互接取任务，清理一个暗灯周围的所有游荡怪物。
- 面朝暗灯后启动脚本。

### 要塞七层刷巨人

- 从要塞出发，击杀七层门口的巨人。
- 当前版本会默认击杀灯怪，不再执行额外的巨人检测。
- 可按需开启旅店休息；休息间隔对巨人生效。

### 离别洞窟

- 开箱难度较高，推荐盗贼主角或专门培养的开箱角色。
- 克拉丽莎可显著简化战斗：放置在前排中央，可有效抵抗魅魔的魅惑。
- 否则推荐 1 速 AOE 输出秒杀魅魔：速度 > 90、魔力 > 450，并搭配后排爱丽丝与前台光环角色补充伤害。
- 洞窟内战斗较多，推荐携带两组 AOE + 增伤组合，或一组组合加两名小号。
- 参考组合：
  - 夏莉莉 + 米拉娜（续航优秀，可开锁）；
  - 叶卡 + 艾莉赛（防偷袭，单光环足够，但续航不足）；
  - 亚当 + 黛博拉（可开锁，续航不足）；
  - 亚当 + 阿贝（先驱斩耗时且伤害无效，不推荐）。

### 卢比肯 三牛

- 从时空跳跃启动，目标点为“击败吾等荣光”，请确保击杀人偶。
- 首次跳人偶可能无法点亮哈肯，需要手动处理。
- 基本流程：跳跃 → 左上角一牛 → 回城休息（可选）→ 右侧两牛 → 跳跃。
- 如需关闭途中回城休息，请关闭“启用旅店休息”。
- 低配参考阵容（4 人）：
  - 2 名战士：160+ 回避、300+ 攻击、+20 冥钢武器（或角鹫之剑），只释放全力一击；
  - 1 名牧师：速度最慢、闪避尽量高、站前排，只释放卡恩提欧斯；
  - 1 名法师/牧师：速度最快、魔力尽量高、站牧师后排，释放 LA 系魔法或秘术。
- 技能启用建议：关闭系统自动战斗，勾选“群体控制”“强力单体”“全体 AOE”。
- 推荐勾选“跳过开箱后恢复”和“启用旅店休息”。
- 参考站位：战士面具左上、牧师叶卡中上、战士王女右上、睡法中下。
- 变种站位：牧师面具左上、战士艾莉赛中上、战士王女右上、牧师叶卡中下。

### 忍洞 / 沙影洞

- 旅店为要塞，请确保要塞可见。
- 不推荐在未完成二周目时使用。
- 需要完成二周目并获得“解除陷阱”知识；通关后从 Boss 房间获取。
- 1F 地图左右下角的隐藏区域极易遗漏，请对照攻略确认地图全开。
- 当前提供：
  - 忍洞一层：自动宝箱；
  - 忍洞一层金箱：重置一层刷金箱。

### 水路船二 lounge

- 请确保船一上半部分地图全部点亮，船二上半部分地图全部点亮。

### 深雪 / 教会区域

- 深雪 R4、R6、R7 与教会区域任务带楼层检测；R10 任务通过楼梯目标点推进。
- 楼层标题存在不同尺寸版本，脚本已兼容两种缩放方式。
- 教会白巨人任务需要高练度、特定角色与技能；作者说明与视频见任务提示。
- 教会白巨人任务需在教会区域设置唯一标记，位置为 `X=26, Y=6`。

### 矿石洞

- 不含 plus 的模式：在指定区域搜索目标。
- 含 plus 的模式：要求点亮所有可能出现的地图，使用自动宝箱搜索，随后前往关底 Boss 处退出。
- plus 模式存在陷阱房，建议勾选“优先不推进任务的路线”。

## 自定义任务

脚本会在启动时读取 `mod/quest.json`，并与内置任务列表合并。自定义任务在中文界面归入“自定义”分类，在英文界面归入“Custom Requests”。

### 目录结构

```text
项目根目录/
├─ mod/
│  ├─ quest.json
│  ├─ images/
│  │  └─ 自定义图片.png
│  └─ 自定义图片.png
├─ wvd.exe
└─ ...
```

- 自定义图片可放在 `mod/images/` 或 `mod/` 下。
- 自定义任务与内置任务内部代号冲突时，会自动追加 `_mod` 后缀。
- 同时提供中英文任务名时优先使用当前界面语言；只提供一种时会自动补齐另一种。

### 最小示例

```json
{
  "MyQuest": {
    "_TYPE": "dungeon",
    "questName": "[自定义]示例任务",
    "questName_en_US": "[Custom] Example",
    "_FloorCheck": "stair_DH_R4",
    "_TARGETINFOLIST": [
      ["position", "右下", [500, 600]],
      ["chest_auto"],
      ["harken", "左上", null]
    ],
    "_EOT": [
      ["press", "DH", ["EdgeOfTown", [1, 1]], 1],
      ["press", "DH-R4", "input swipe 650 250 650 900", 1]
    ],
    "_RTT": ["City_DHI", "input swipe 54 1346 302 1571", [500, 1100]],
    "_TIPS": "这是一个示例任务。"
  }
}
```

### 任务字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `_TYPE` | 是 | `dungeon` 或 `quest` |
| `questName` | 至少一项 | 中文任务名 |
| `questName_en_US` | 至少一项 | 英文任务名 |
| `questCategory` | 否 | 自定义任务会统一归入“自定义” |
| `questCategory_en_US` | 否 | 自定义任务会统一归入“Custom Requests” |
| `_TARGETINFOLIST` | 地下城任务必填 | 任务点列表 |
| `_EOT` | 地下城任务通常需要 | 从城镇进入地下城的流程 |
| `_RTT` | 否 | 从地下城返回城镇的流程 |
| `_preEOTcheck` | 否 | 进本前需要先点击的界面 |
| `_FloorCheck` | 否 | 楼层检测模板名，可为字符串或列表 |
| `_TIPS` | 否 | 任务提示，选择任务时弹窗显示 |
| `_SPECIALDIALOGOPTION` | 否 | 特殊对话选项图片列表 |
| `_SPECIALFORCESTOPINGSYMBOL` | 否 | 出现即停止任务的图片列表 |
| `_SPECIALJUNK` | 否 | 开箱时要检测的特殊杂物图片 |
| `_SPECIALJUNK_CALLBACK` | 否 | 检测到特殊杂物后切换的目标任务代号 |

### 任务点格式

```json
["目标类型", "拖动方向或 swipe 指令", "检测区域或坐标"]
```

**目标类型：**

| 目标类型 | 说明 |
| --- | --- |
| `position` | 前往指定坐标；第三个参数为 `[x, y]` |
| `chest` | 搜索宝箱；检测区域可省略，脚本会自动排除地图边缘 |
| `chest_auto` | 使用面板“自动宝箱”按钮 |
| `mark_auto` | 使用面板“自动标记寻路”按钮 |
| `harken` / `Bharken` | 搜索哈肯/大哈肯；第三个参数可填 `stair_xxx` 以校验楼层 |
| `stair_xxx` | 搜索楼梯或楼层入口 |
| `leaveDung` | 直接退出地下城 |
| `stay` | 原地等待约 2 秒 |
| 自定义图片名 | 搜索对应图片 |

**拖动方向：**

- `左上`、`右上`、`左下`、`右下`；
- `null`：按默认顺序向多个方向搜索；
- 也可直接填写 `input swipe x1 y1 x2 y2`。

**检测区域：**

- 多个矩形：`[[x, y, w, h], ...]`；
- `position` 可填 `"default"`，使用内置默认区域；
- `null`：使用默认区域。

### 进入与回城流程

`_EOT` 中每一项的格式为：

```json
["press", "目标图片", "找不到时的兜底动作", 重试间隔]
```

- 兜底动作可以是图片名、坐标、`"return"` 或 `input swipe ...`；
- 最后一项也可以使用 `["press", "intoWorldMap", ["目标", "swipe 指令", [x, y]]]` 的形式通过世界地图进入。

`_RTT` 的格式为：

```json
["城市图片名", "拖动指令", [任意键点击位置]]
```

### 特殊杂物与任务切换

- `_SPECIALJUNK` 用于在开箱时检测指定杂物；
- 命中后可通过 `_SPECIALJUNK_CALLBACK` 切换到另一任务；
- 启用该功能的任务会禁用快速开箱与正常开箱的多次点击，以避免过早关闭宝箱界面；
- 该检测仍可能存在漏报，请以任务说明为准。

### 特殊对话

- `_SPECIALDIALOGOPTION` 中的图片一旦被识别，脚本会点击对应选项并关闭角色界面；
- 任务可在代码层配置回调，以执行额外逻辑；
- 适用于需要选择特定分支、购买特定物品或避免卡对话的场景。

## 从源码构建

### 运行环境

- Windows 10 / 11
- Python 3.10

### 安装依赖

```bash
pip install -r requirements.txt
```

### 编译本地化文件

```bash
python -m babel.messages.frontend compile -d locale -D messages
```

### 从源码运行

```bash
python src/main.py
```

### 打包为可执行文件

可以使用项目根目录下的：

```text
用于本地测试的打包脚本.bat
```

该脚本会创建 `.venv`、安装依赖、编译本地化文件，并使用 PyInstaller 生成 `dist/wvd/`。

也可以手动执行：

```bash
pyinstaller --onedir ^
  --paths=src ^
  --collect-submodules=ppadb ^
  --add-data "resources;resources/" ^
  --add-data "locale;locale/" ^
  src/main.py -n wvd
```

### 自动发布

推送至 `master` 分支后，GitHub Actions 会：

1. 从 `src/main.py` 读取版本号；
2. 编译本地化文件；
3. 使用 PyInstaller 构建；
4. 打包并生成 MD5；
5. 创建 GitHub Release；
6. 正式版本会更新 GitHub Pages 上的 `release.json`。

## 注意事项与已知限制

1. **分辨率固定**：脚本图像识别基于 1600 × 900、240 DPI，其他分辨率可能导致识别失败。
2. **语言必须一致**：脚本中的“游戏内的语言”必须与模拟器内游戏语言一致。
3. **地图必须探索**：大多数任务要求目标区域地图已探明；使用自动宝箱或标记寻路时尤其重要。
4. **标记专用**：使用 `mark_auto` 的任务通常要求目标楼层无其他自定义标记。
5. **时间跳跃任务先手动验证**：首次运行建议观察，避免特殊剧情、工会弹窗或悬赏提示导致流程中断。
6. **关闭对话自动选择**：部分任务依赖脚本自行选择分支。
7. **“每场战斗重置”属于高级功能**：请先理解游戏内“重复上一次”的机制。
8. **多开模拟器**：目标模拟器未运行时，建议让脚本自行启动；同时存在多个模拟器时，重启模拟器可能影响全部实例。
10. **钓鱼不购买鱼饵**：脚本只使用仓库中已有的鱼饵。
11. **部分中文资源仍在完善**：如遇到识别失败，请保留日志与截图反馈。
12. **使用风险自负**：请遵守游戏用户协议与相关法律法规，自行评估自动化工具的使用风险。
